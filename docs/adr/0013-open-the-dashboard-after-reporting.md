# 0013. 送信スクリプトは、報告がダッシュボードに届いたらブラウザで開く

- ステータス: 廃止(Superseded by 0017)
- 日付: 2026-11-16

## 文脈

- PR を出した Claude が `toriage-report` で報告を送っても、ダッシュボードは人が開くまで目に入らない。開くには `/toriage:open` を頼むか、URL を自分で開く
- 画面は自分では読み直さない。タブに戻ったときと開いたときにだけ一覧を取る
- シェルからは、すでに開いているタブを探して前に出せない(ブラウザごとの AppleScript などが要る)。`open` や `xdg-open` で URL を開くと、ふつうは新しいタブになる
- 差し戻しで裏で再開した Claude も、直したあと `toriage-report` で送り直す(0011)
- toriage は人に渡して使ってもらうこともある

## 検討した選択肢

1. 送信スクリプトが、報告が届くたびに開く
2. ダッシュボードに無かった PR のときだけ開く。サーバーが新しいカードかを返す
3. 開いているタブが無いときだけ開く。画面が数十秒ごとにサーバーに知らせて自分で読み直し、知らせが途絶えていれば開く

止める手段は、環境変数で止める案と、付けない案を比べた。

## 決定

1 にし、環境変数で止められるようにする。高橋さんが選んだ。

- `toriage-report` は、ダッシュボードが報告を保存したと答えたあと、送った先の URL(`TORIAGE_URL`、なければ `http://127.0.0.1:8787`)をブラウザで開く。macOS は `open`、ほかは `xdg-open` を使う。macOS でないときは、`DISPLAY` か `WAYLAND_DISPLAY` があるときだけ開く
- 開く命令は `nohup` を付けて裏で動かし、出力は捨て、待たない。命令が無いときや開けなかったときも、送れたので 0 で終わる
- inbox に保存したとき、もっと新しい報告があって置き換えなかったときは開かない
- `TORIAGE_OPEN` が `0` のときは開かない
- 差し戻しのあと裏の Claude が送り直したときも開く

## 理由

- 送信スクリプトだけを変えれば済み、サーバーと画面は変えない
- 毎回ブラウザが前に出るので、PR を出したことに気づける。差し戻しで直して送り直したことにも気づける。画面が自分では読み直さないので、開いたままのタブだけでは気づきにくい
- 2 では、差し戻しのあとの送り直しが、タブに戻るまで画面に出ない
- 3 では、開いたタブが後ろにあると前に出ず、気づけない。後ろのタブはブラウザがタイマーを間引くので、開いているのに開いていないと判定することもある。変更も一番大きい
- `xdg-open` は、ブラウザが動いていないとブラウザが閉じるまで戻らないことがある。待つと報告を送った Claude が止まるので、裏で動かす。そのとき Linux では、`xdg-open` が起動したブラウザが送信スクリプトの子として動く。報告を送ったあとに端末を閉じても、ブラウザが一緒に閉じないよう `nohup` を付ける。macOS の `open` はブラウザを OS に起動させるので、子にはならない
- 画面の無い Linux(SSH でつないだときなど)では、`xdg-open` が端末のブラウザ(`lynx`、`w3m` など)を探し、端末の無いまま裏で動かしてしまう。開いても見えないので開かない
- 開いてほしくない人や、ブラウザの無い場所で動かす人、テストのために、止める手段を 1 つ置く

## 受け入れたトレードオフ

- すでにタブを開いていても新しいタブが増える。報告を送るたびに増えるので、ときどき閉じる手間がかかる
- 作業中でも、報告が届くとブラウザが前に出る
- Linux でブラウザが動いていなかったときは、ブラウザが送信スクリプトと同じプロセスグループに入る。そのグループごと止められると(Bash の割り込みや、Claude Code が終わるときの後始末)、ブラウザも止まることがある。`setsid` で切り離せば防げるが、macOS には無いので分岐が増える。ふだんはブラウザがもう動いていて、`xdg-open` は頼むだけで戻るので、分けない
- inbox に保存した報告を、次に起動したサーバーが取り込んだときは開かない。開くのは送信スクリプトなので、送ったときに届かなかった報告は、ダッシュボードを開いたときに気づく
- SSH で Mac に入って Claude Code を動かすと、その Mac の画面にタブが開く。見えないだけで害は無いので、画面の有無は Linux でだけ見る。要らなければ `TORIAGE_OPEN=0` にする
- Windows(Git Bash)や、`xdg-open` の無い WSL では開かない。toriage が対象にするのは macOS と Linux
- 開けなかったことは知らせない。開かないときは、自分で開くか `/toriage:open` を使う
- 設定が 1 つ増える

## 再検討する条件

- タブが増えるのが手間になったとき。3 の、画面が自分で読み直す形を考える
- 前に出てくるのが作業の邪魔になったとき
